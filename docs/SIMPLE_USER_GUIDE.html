4. How to handle customer messages

Messages = enquiries from the “Contact Us” form.

  1. Tap Messages in the menu.
  2. Unread messages stand out in the list.
  3. Tap a message to read name, email, phone, subject, and message.
  4. Reply by email or phone — the admin does not send replies automatically.
  5. Opening a message marks it as read.
5. How to handle quote requests

Quotes = when someone asks for a price on a product.

  1. Tap Quotes in the menu.
  2. Tap a quote to see customer details, product, quantity, and notes.
  3. Contact the customer with your price by email or phone.
  4. Opening a quote marks it as read.
Customers can also use Help → Chat on WhatsApp on the website.
6. How to add a new product
  1. Go to Products.
  2. Tap Add Product.
  3. Fill in the fields below.
  4. Tap Save.
Name
e.g. 5 HP Induction Motor
Category
Pick the right group
Short description
1–2 lines for listings
Description
Full details on product page
Image
Upload photo or paste link
Price
Starting price in ₹ (optional)
Active
Turn ON so customers can see it
Featured
Turn ON for homepage (optional)

More photos: Open product → Images section → upload → drag to reorder → set Primary.

7. How to edit or remove a product

Edit

  1. Products → find item → Edit → change → Save.

Hide from website (keep in admin)

Turn Active OFF and save.

Delete forever (Admin only)

Tap Delete. Cannot be undone.

8. How to manage categories
  1. Go to Categories.
  2. Add — name, description, image (optional).
  3. Reorder — drag up/down.
  4. Edit — tap to change.
  5. Active OFF — hide from website.

No image? The site shows the first letter of the category name.

9. How to update homepage banner
  1. Go to Hero Slider.
  2. Each row = one slide on homepage.
  3. Set Title, Subtitle, Image, and button text/link.
  4. Drag or use sort order for slide sequence.
  5. Active OFF hides a slide without deleting it.
10. How to add a testimonial
  1. Go to Testimonials → Add.
  2. Enter customer name, company, job title.
  3. Add short quote and longer story (optional).
  4. Set rating (1–5 stars), photo (optional).
  5. Featured = homepage · Active = visible on site.
  6. Tap Save.

Admin
Everything — delete, users, logs

See Read Only? Ask an Admin to upgrade your role.

14. Good habits
  1. Check Messages and Quotes daily.
  2. Keep phone and WhatsApp correct in Settings.
  3. Use clear product photos.
  4. Turn Active OFF instead of deleting if you may list again.
  5. Tap View Site after changes to check the live site.
  6. Logout on shared computers.
15. Common problems
Cannot log in
Check email/password; ask Admin
Changes not visible
Tap Save; refresh site; check Active is ON
No WhatsApp button
Settings: chat_widget_enabled = true + phone filled
Image not showing
Wait and save again; try smaller file
Forgot password
Ask Admin or Profile → Change Password
